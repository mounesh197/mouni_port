# Mounesh M R — Portfolio

A multi-page personal portfolio built with plain HTML, CSS and JavaScript.

## Files
- `index.html`, `about.html`, `education.html`, `skills.html`, `projects.html`, `hobbies.html`, `contact.html` — the pages
- `style.css` — all styles (dark theme, blue accents, animations)
- `script.js` — menu, scroll animations and contact form
- `assets/` — images

## Update your contact details
Search all files for these placeholders and replace them with your own:
- `your.email@example.com` (also set `CONTACT_EMAIL` at the bottom of `script.js`)
- `https://www.linkedin.com/in/your-profile`
- `https://github.com/your-username`
- `https://www.instagram.com/your-handle`

## Publish free on GitHub Pages
1. Create a new public repository on GitHub (e.g. `your-username.github.io`).
2. Upload every file in this folder (keep `index.html` at the top level).
3. Go to **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then **Save**.
4. After a minute your site is live at `https://your-username.github.io/`.
